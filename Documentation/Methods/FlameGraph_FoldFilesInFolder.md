   FlameGraph_FoldFilesInFolder ({folderPath}) : numFiles     FlameGraph_FoldFilesInFolder ({text}) : longint          DESCRIPTION       Takes a folder of unfolded flamegraph files created by this component       and combines all the results in each file into a single folded file       that flamegraph.pl is used to turn the folded fileds into SVGs.           If no path is provided then a select dialog will ask for a folder.
